# JSON Report Schemas

Reference for reading eval report JSON files programmatically.

## eval_stats.json (Layer 2 — LLM grader results)

Generated by `make eval-stats` / `eval_stats.py`.

```json
{
  "exported_at": "2026-05-11T...",
  "title": "BKH Eval Stats",
  "files": ["bkh_regression_main.jsonl"],
  "stats": {
    "<label>": {
      "n_total": 50,
      "sentiment": {
        "n_liked": 25,
        "n_disliked": 25,
        "n_unrated": 0,
        "rating_coverage_rate": 1.0,
        "dislike_like_ratio": 1.0
      },
      "has_sources_rate": 0.82,
      "grader_results": {
        "<grader_name>": {
          "pass_rate": 0.72,
          "avg_score": 0.78,
          "threshold": 0.75,
          "passed": false,
          "n_scored": 50
        }
      }
    }
  }
}
```

Grader names: `answer_relevancy`, `completeness`, `escalation`, `grounding`,
`deepeval_answer_relevancy`, `deepeval_completeness`, `deepeval_escalation`,
`ragas_context_precision`, `ragas_faithfulness`

## VA staging smoke JSON

Located at: `data/datasets/support-agents/va_staging/evals/smoke_YYYYMMDD_HHMMSS.json`

```json
{
  "run_id": "smoke_20260509_212709",
  "n_tasks": 50,
  "grader_results": {
    "answer_relevancy": {"pass_rate": 0.68, "avg_score": ...},
    "ragas_faithfulness": {"pass_rate": 0.18, "avg_score": 0.347}
  },
  "tasks": [
    {
      "task_id": "...",
      "query": "...",
      "response": "...",
      "sources": [...],
      "grader_scores": {...}
    }
  ]
}
```
