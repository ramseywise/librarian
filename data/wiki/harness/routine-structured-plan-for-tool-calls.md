# Routine Structured Plan for Tool Calls

Routine (a preprint from Digital China AI Research) is a structured plan the agent follows: an ordered list of steps, each naming the tool to call, optionally with input and output descriptions and branches. A small instruct model can execute the routine while a larger one writes it, and a variable-memory mechanism stores long tool outputs under a key so the model passes the key and not the value. Both of those design claims are stated, not measured; the paper has no ablation of variable memory and no cost or latency numbers.

## Setup

An HR agent with 25 MCP tools and 7 routines of 4 to 7 steps each. The test set holds 1,148 step-level samples decomposed from 200 distilled traces, generated with GPT-4o. Each sample is teacher-forced with the true earlier steps supplied, so mistakes never pile up, and scoring is step by step. In the "no routine" arm the model sees the query plus the tool list in one prompt and answers once, with no ReAct loop.

## Reported results (self-reported)

- **Overall accuracy.** GPT-4o goes from 41.1 to 96.3 with a branching routine, GPT-4-Turbo from 43.5 to 99.0, Claude-3.7-Sonnet from 43.9 to 99.3, Qwen3-14B from 32.6 to 83.3 and Qwen2.5-7B from 14.9 to 49.7. Without a routine no model exceeded 50%.
- **Failure mode.** Tool selection accounts for over 85% of errors without a routine, while structure and parameter accuracy are already high.
- **Tool names matter most.** Removing them costs most models 5 to 15 points. Parameter descriptions help weaker models and are mixed for Qwen3.
- **Plan quality.** A rough user draft already helps (GPT-4o 71.2), AI refinement reaches 90.9, and a human routine 96.3.
- **Distractors hurt.** Supplying several routines with one applicable drops GPT-4o from 96.3 to 76.6 at two routines and 88.6 at five; the non-monotone recovery is only hypothesised.
- **Distillation.** LoRA fine-tuning Qwen3-14B on 537 routine-guided samples reaches 90.2 with no routine at inference and 95.5 with one.

## Limits

- Single internal scenario, one run, no variance, and a test set generated by GPT-4o from the same routines, which favours routine-following and GPT-4o.
- The routine arms receive expert-written or GPT-4o-refined plans, so the comparison measures plan quality, not plan against no plan. No ReAct or model-generated-plan baseline is run.
- The scenario-specific fine-tune shares its distribution with the test set. The prose says generic routine-following fine-tuning declined on autonomous planning, but the table shows rises for three of four models.
- Branching generally lowered accuracy slightly for weaker models.
