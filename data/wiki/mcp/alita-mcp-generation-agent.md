# Alita

Qiu et al. (Princeton, Tsinghua, SJTU and others; a May 2025 preprint) start from Open Deep Research with smolagents, remove the predefined tools and add a loop that builds tools when a task needs one. The authors argue predefined toolkits have incomplete coverage, limited flexibility, and a mismatch with tools not written in Python.

## Loop

1. The manager agent calls MCP Brainstorming, which identifies what capability is missing and drafts a spec for the tool; the authors give models' tendency to overrate themselves as the reason for this step.
2. The web agent (browser, search and GitHub search tools) finds code to base the tool on.
3. ScriptGeneratingTool writes the script plus environment and cleanup scripts; CodeRunningTool runs it in its own Conda environment, with no containers.
4. A script that works is registered in the "MCP Box" for reuse.

## Results (self-reported)

- On GAIA validation, a Claude-Sonnet-4 manager with GPT-4o gave 75.15% at pass@1 against 87.27% at pass@3, and Claude-3.7-Sonnet with GPT-4o gave 72.73% and 86.06%. The same table lists OpenAI Deep Research at 67.36, OWL at 69.09, A-World at 69.70, AutoAgent and ODR-smolagents at 55.15 each, and Octotools at 18.40. Pass@3 keeps the best of three runs; baseline rows are single figures.
- Reuse: ODR-smolagents with GPT-4o rose from 27.88% to 33.94% with Alita's MCPs; a GPT-4o-mini base rose from 21.82% to 29.09% with MCPs generated by Claude-3.7-Sonnet runs, which the authors call cheaper than distillation.
- Alita itself on GPT-4o-mini scored 43.64%, against 72.73% for the stronger coder.
- 100 random samples per benchmark: Mathvista 74% and PathVQA 52% pass@1, against 68 and 47 for Octotools.

## Limits

- Authors concede Alita relies on the model's coding ability and does worse than a conventional generalist agent when that is poor.
- Only pass@1 is like for like, and baseline figures appear copied from elsewhere without a stated method.
- The reuse experiments gather MCPs while running GAIA and then score on GAIA, and the paper is silent on whether questions were held out.
- No component ablation, no cost or latency, no safety analysis though the agent runs downloaded code with only a Conda environment; one case study (a YouTube subtitle crawler).
- The extraction notes the paper shows no transport, schema or discovery, so "MCP" here means a packaged reusable script, and that the OpenAI Deep Research level 2 and 3 scores differ between Table 1 and Figure 1.
- Models and the leaderboard claim date from May 2025.
