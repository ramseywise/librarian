# EfficientRAG

EfficientRAG (arXiv 2408.04259, preprint) removes the LLM from the multi-hop loop. A Labeler and Tagger is a token classifier that marks useful tokens in each retrieved chunk and tags it Continue or Terminate. A Filter then forms the next query out of those marked tokens. Retrieval is Contriever-MSMARCO; a single LLM call produces the final answer. Training data is synthetic, generated by Llama-3-70B.

## Results (self-reported)

- Recall 81.84 at 6.41 chunks on HotpotQA; on 2WikiMQA, 84.08 using 3.69 chunks, where SelfAsk reaches 88.90 using 33.68. MuSiQue recall is low at 49.51.
- Llama-3-8B reader accuracy: HotpotQA 57.86, MuSiQue 20.00, 2Wiki 53.41. This was second best on two datasets and best on none.
- Latency on 200 MuSiQue samples: 3.62 s and 1.00 LLM calls against 27.47 s and 7.18 calls for SelfAsk.
- Cross-dataset transfer scores 53.38 and 56.59.

## Limits

- Llama-3-8B is the main reader (GPT-3.5 on one dataset). Open-domain multi-hop only.
- Training data is built per dataset; single runs; latency measured on one dataset.
