# Doc-to-LoRA

Context distillation fine-tunes a model so it behaves as if a document were in its prompt, but it needs an optimisation run per document. Charakorn et al. (2026) meta-train a hypernetwork to produce that adapter directly. The training objective is a KL divergence between the model's outputs with the context and its outputs with the generated adapter and no context.

## Setup

Target model gemma-2-2b-it, a 309M-parameter hypernetwork, one rank-8 LoRA per 8K-token chunk on the MLP down-projection, with chunk adapters concatenated along the rank dimension. Training used about 3.2M contexts from FineWeb-Edu plus QA sets, with queries generated by gemma-3-12b-it and teacher logits kept. The conclusion gives about five days on 8 H200 GPUs for this model (self-reported).

## Results (self-reported)

- Latency: under 1 s on SQuAD, against about 40 s for oracle context distillation (optimised on the target query) and over 100 s for distillation with generated queries.
- Quality: 82.5% of the in-context ROUGE-L upper bound on SQuAD, roughly what LLMLingua-2 gets at 40% of the original length.
- Needle in a haystack, trained on 32 to 256 token contexts: near-perfect to about 40K tokens, beyond the base model's 8K window, with extra generation memory under 50 MB against over 12 GB for the base model at 128K.
- 2WikiMultihopQA up to 32K tokens: normalised score 0.857 batched against 0.901 for oracle distillation, with distillation on 25 generated queries at 0.745 and 465 s latency.
- A vision-language model as encoder gave a text-only target 75.03% on Imagenette. KL loss beat next-token loss in an early-checkpoint ablation, and rank 16 beat rank 8 on two of three sets.

## Limits

- The hypernetwork is retrained per target model, and a performance gap to in-context use remains.
- Knowledge interference: with irrelevant stored context D2L fell below the base model (0.096 against 0.201 with an assistant prompt). The authors hypothesise it assumes queries relate to the stored text, and an untested fix is suggested.
- Only LoRA, models of 2B to 7B, mostly extractive QA scored by ROUGE-L, and a single 4-digit needle. On Mistral-7B long-context QA every internalisation method stayed near the no-context baseline.
- The extraction notes that its table cells run together and that the MultiFieldQA result (about 0.48 against 1.041 for oracle distillation) is weaker than the 2WikiMultihopQA one. Distillation baselines used only 5 to 25 queries.
- No comparison with KV-cache compression or agent-history compaction.
