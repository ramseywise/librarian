# Climbing Stairs

**Source**: [https://leetcode.com/problems/climbing-stairs/](https://leetcode.com/problems/climbing-stairs/)

## Problem Description

You are climbing a staircase with `n` steps. Each time you can climb 1 or 2 steps. In how many distinct ways can you reach the top?

**Example**: `n = 3` → `3` ways: `[1+1+1, 1+2, 2+1]`
