# Pillar 0 — Programming Foundations (DSA, Python, SQL)

The bedrock under everything else: write clean, efficient code, solve algorithmic problems
under pressure, and translate data questions into working queries. This pillar doesn't
sequence from another — it runs in parallel with or before Pillar 1. Most interview loops
include a coding screen at some stage.

## Learn it in the curriculum

The teaching lives in the chapters. Work them in this order, then use the [interview guide](interview-guide.md) as the recall sheet.

| Chapter | What it covers |
|---|---|
| [Python](../../../programming/python/readme.md) | Foundations, informatics, the language for engineers |
| [SQL](../../../programming/sql/readme.md) | Queries from scratch, with offline exercises |
| [TypeScript](../../../programming/typescript/readme.md) | Types, generics and exercises |
| [SQL for analytics](../../../data-analytics/06-applied-analyses/notes/06-sql-for-analytics.md) | The analytics patterns screens ask for |

## Drill it

- [Python](../../../drills/python/readme.md), [SQL](../../../drills/sql/readme.md) and
  [TypeScript](../../../drills/typescript/readme.md) tracks.
- [Hello, Interview!](../../../drills/coding/dsa/readme.md): pattern reference with solutions, for
  refreshing a pattern, not rehearsing cold.
- [Coding prompts](../../../drills/coding/prompts/readme.md) and
  [seeded-bug problems](../../../drills/coding/problems/readme.md).
- For cold reps on classic problems, use HackerRank and LeetCode directly. Fluency first, then
  pattern recognition, then timed mixed practice.

[interview-guide.md](interview-guide.md) — DSA checklist, Python patterns, SQL patterns,
