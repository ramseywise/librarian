# Python

Python's teaching lives in [`programming/python/`](../../python/readme.md), and the
[seeded-bug problems](../coding/problems/readme.md) and [coding prompts](../coding/prompts/readme.md)
are written in it.

For cold reps on a fixed problem set, use the HackerRank Python track (Introduction, Basic Data
Types, Strings, Sets, Math, Itertools, Collections, Date and Time, Errors and Exceptions, Classes,
Built-ins, Python Functionals, Closures and Decorators, NumPy, Regex and Parsing, XML, Debugging)
and LeetCode's pattern lists (arrays and hashing, two pointers, sliding window, linked lists).
Solutions to those stay local and are not in this repo.
